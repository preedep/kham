# LK82 — Lorchirachoonkul Phonetic Encoding (1982)

The most widely used Thai soundex algorithm. Encodes a Thai word into a
**4-character code** where the first character represents the initial consonant
group and subsequent characters represent following consonant groups (vowels,
tone marks, and silent consonants ignored).

## Algorithm Steps

1. Extract only Thai consonants from the input (skip vowel signs, tone marks, ์, ๆ, ฯ, digits, Latin)
2. Map each consonant to its LK82 group code (table below)
3. Remove consecutive duplicate codes (adjacent consonants in the same group collapse to one code)
4. Take the first 4 codes; pad with `'0'` if fewer than 4
5. Return as a 4-character ASCII string

## LK82 Consonant Group Table

> **Source:** Lorchirachoonkul (1982); also implemented in PyThaiNLP (`pythainlp/soundex/lk82.py`).
> Verify against the PyThaiNLP source for authoritative group assignments.

| Code | Thai consonants | Initial sound |
|------|----------------|---------------|
| `0` | อ | glottal / vowel carrier (null onset) |
| `1` | ก ข ค ฆ | /k/, /kʰ/ |
| `2` | จ ช ซ ศ ษ ส ฉ ฌ ญ | /tɕ/, /tɕʰ/, /s/ |
| `3` | ต ถ ท ธ ฏ ฐ ฑ ฒ ด ฎ | /t/, /tʰ/, /d/ |
| `4` | บ ป พ ผ ภ ฝ ฟ | /b/, /p/, /pʰ/, /f/ |
| `5` | ม | /m/ |
| `6` | น ณ | /n/ |
| `7` | ง | /ŋ/ |
| `8` | ล ร ฬ | /l/, /r/ |
| `9` | ว | /w/ |
| `A` | ย | /j/ |
| `B` | ห ฮ | /h/ |

> **Note:** Some published versions use numeric-only codes (0–8) with slightly different groupings.
> PyThaiNLP's implementation is the authoritative open-source reference for this project.

## Characters to Skip

Skip these Unicode ranges entirely — do not emit a code for them:

| Range | Description |
|---|---|
| `U+0E30`–`U+0E3A` | Sara vowels (สระ ะ า ิ ี ึ ื ุ ู) |
| `U+0E40`–`U+0E44` | Leading vowels (เ แ โ ไ ใ) — appear before consonant in text |
| `U+0E47`–`U+0E4E` | Mai diacritics (็ ั ่ ้ ๊ ๋ ์ ๎) |
| `U+0E4C` | Thanthakat ์ — marks silent consonant |
| `U+0E45` | Lak khang yao ๅ |
| `U+0E46` | Maiyamok ๆ |
| `U+0E31` | Mai han akat (ั) |

## Rust Implementation Sketch

```rust
pub fn lk82(word: &str) -> alloc::string::String {
    const CODE_LEN: usize = 4;
    const PAD: char = '0';

    let mut codes: alloc::vec::Vec<u8> = alloc::vec::Vec::new();
    let mut last_code: Option<u8> = None;

    for ch in word.chars() {
        // skip non-Thai and diacritics
        if !is_thai_consonant(ch) {
            continue;
        }
        // also skip silent consonants marked with ์ — but ์ comes AFTER
        // the consonant, so we need one-char look-ahead or a pre-pass.
        // Simplest: pre-strip thanthakat-marked consonants before the loop.

        let code = consonant_to_lk82(ch);
        if Some(code) != last_code {
            codes.push(code);
            last_code = Some(code);
        }
        if codes.len() == CODE_LEN {
            break;
        }
    }

    // pad to CODE_LEN with '0'
    while codes.len() < CODE_LEN {
        codes.push(b'0');
    }

    alloc::string::String::from_utf8(codes).unwrap()
}

fn is_thai_consonant(c: char) -> bool {
    // ก (U+0E01) through ฮ (U+0E2E)
    ('\u{0E01}'..='\u{0E2E}').contains(&c)
}

fn consonant_to_lk82(c: char) -> u8 {
    match c {
        'อ'                                             => b'0',
        'ก'|'ข'|'ค'|'ฆ'                               => b'1',
        'จ'|'ช'|'ซ'|'ศ'|'ษ'|'ส'|'ฉ'|'ฌ'|'ญ'         => b'2',
        'ต'|'ถ'|'ท'|'ธ'|'ฏ'|'ฐ'|'ฑ'|'ฒ'|'ด'|'ฎ'    => b'3',
        'บ'|'ป'|'พ'|'ผ'|'ภ'|'ฝ'|'ฟ'                  => b'4',
        'ม'                                             => b'5',
        'น'|'ณ'                                        => b'6',
        'ง'                                             => b'7',
        'ล'|'ร'|'ฬ'                                    => b'8',
        'ว'                                             => b'9',
        'ย'                                             => b'A',
        'ห'|'ฮ'                                        => b'B',
        _                                               => b'0',
    }
}
```

> **Warning:** The above `consonant_to_lk82` table is an approximation.
> Cross-check every consonant assignment against the PyThaiNLP reference
> implementation at `pythainlp/soundex/lk82.py` before shipping.

## Handling Silent Consonants (ตัวการันต์)

Consonants followed by Thanthakat `์` (U+0E4C) are silent and must be skipped.
The challenge: `์` appears *after* the consonant in the Unicode sequence.

Recommended pre-processing approach:

```rust
// Remove consonant + ์ pairs before main loop
fn strip_silent_consonants(s: &str) -> alloc::string::String {
    let chars: alloc::vec::Vec<char> = s.chars().collect();
    let mut out = alloc::string::String::new();
    let mut i = 0;
    while i < chars.len() {
        if i + 1 < chars.len() && chars[i + 1] == '\u{0E4C}' {
            i += 2;  // skip consonant + ์
            continue;
        }
        out.push(chars[i]);
        i += 1;
    }
    out
}
```
